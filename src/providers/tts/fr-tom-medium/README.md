# French Piper voice: Tom medium

Bundled replacement for Siwis, used by French Piper in the checkout and exports.
The model produces mono audio at 44,100 Hz.

Source: [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/c10ece1aade47bb51c153c893d14e5bf8e5b7117/fr/fr_FR/tom/medium), revision `c10ece1aade47bb51c153c893d14e5bf8e5b7117`.
`fr_FR-tom-medium.onnx` and its `.onnx.json` configuration are stored here as
`model.onnx` and `model.onnx.json`. See the original [MODEL_CARD](MODEL_CARD)
for attribution and the AGPLv3 license.
